truck-dispatch-toolkit

The math a U.S. truck dispatcher or owner-operator runs every day: true rate per mile, load profit, detention claims, IFTA fuel tax estimates, and trip fuel planning.

View source on GitHub

Runs fully in your browser, files never leave your device. There is nothing to upload: just type your numbers.

Calculators

Uses the built-in approximate 2025 rate table from the library. An estimate for lane costing, not a tax filing. Verify current rates before filing.

The full toolkit

True rate: loaded rate lies, this prices every mile including deadhead and grades it against your break-even
Load profit: gross minus fuel, factoring, driver pay, tolls and lumper, with margin and profit per mile
Hours of service: an 11, 14 and 70 hour feasibility check for a planned trip (estimate, not legal advice)
Detention: dwell minus free time and grace, rounded up to your billing increment, plus a claim letter in the CLI
IFTA: gallons and tax owed per state from miles and MPG, with your own rate table in the library
Lane book, broker scorecard, fuel planning, check-call schedules and accessorials round out the CLI and library

Prefer the command line?

Zero dependencies, Node.js 18 or newer. This page runs the same library code the CLI uses.

git clone https://github.com/aamirtechs/truck-dispatch-toolkit.git
cd truck-dispatch-toolkit
node bin/cli.js rate --linehaul 2400 --loaded-miles 800 --deadhead-miles 100 --cost-per-mile 2.10
node bin/cli.js profit --linehaul 3000 --loaded-miles 1000 --mpg 6.5 --fuel-price 3.80

Hours-of-service and IFTA outputs are planning estimates, not legal or tax advice.
